เมื่อเปิดบันทึกและบันทึกสำเร็จ ความคืบหน้าจะกลับมาได้บนเครื่องนี้

ข้อมูลทั้งหมดเป็นข้อมูลจำลองเพื่อการศึกษา · ไม่มีบัญชีผู้ใช้หรือระบบส่งคำตอบ

ความเป็นส่วนตัว

แอปไม่มี analytics หรือระบบส่งข้อมูล เมื่อเลือกเปิดบันทึก ความคืบหน้าและสะท้อนคิดจะอยู่ใน IndexedDB บนเครื่องนี้ และ localStorage เก็บเพียงตัวเลือกเปิดบันทึก เครื่องที่ใช้ร่วมกันอาจเห็นข้อมูลเดิมได้ เบราว์เซอร์อาจลบข้อมูลหรือปฏิเสธการบันทึก ผลแก้ไขได้และไม่ใช่ผลการเรียนที่ยืนยันแล้ว ไฟล์ PDF ที่ดาวน์โหลดไม่ถูกลบเมื่อล้างข้อมูลในแอป ผู้ให้บริการ GitHub Pages อาจบันทึก IP ตามนโยบายของบริการ
