# ตรวจรับบน iPad Safari ก่อนใช้ในชั้นเรียน

สถานะ: ยังต้องตรวจบนอุปกรณ์จริง การทดสอบ WebKit จำลองช่วยตรวจถดถอย แต่ไม่ครอบคลุมคีย์บอร์ด iPad และ VoiceOver จริง

บันทึกรุ่น iPad เวอร์ชัน iPadOS/Safari วันที่ และผู้ทดสอบเมื่อดำเนินการ

## การแสดงผลและการสัมผัส

- [ ] เปิดจาก GitHub Pages และโหลดหน้าใหม่ได้โดยไม่มีไฟล์ขาด
- [ ] ใช้ได้ทั้งแนวตั้งและแนวนอน รวมถึง Split View
- [ ] หน้าเว็บไม่ล้นแนวนอน ตารางและกราฟเลื่อนภายในพื้นที่ของตัวเองได้
- [ ] ตัวอักษรไทย สระ และวรรณยุกต์แสดงครบ และอ่านได้เมื่อเพิ่มขนาดตัวอักษร
- [ ] ปุ่มและรายการเลือกกดได้สะดวกโดยไม่แตะผิด
- [ ] แตะแท่ง จุด และส่วนกราฟวงกลมแล้วอ่านค่าจากข้อความด้านล่างได้
- [ ] อ่านตารางแทนกราฟได้ โดยเฉพาะข้อมูลที่อยู่ใกล้กันหรือส่วนวงกลมขนาดเล็ก
- [ ] ขอบจอและการหมุนอุปกรณ์ไม่บังปุ่มหรือข้อความ

## กิจกรรมและคีย์บอร์ด

- [ ] ทำครบ 5 สถานการณ์ใน 4 แล็บ โดยเห็นคำแนะนำรายเกณฑ์
- [ ] คำตอบผิดไม่เพิ่มจำนวนกิจกรรมที่ผ่านเกณฑ์
- [ ] คำคาดการณ์ผิดไม่ลด Mastery และต้องกดบันทึกก่อนเริ่มทดลอง
- [ ] ต้องบันทึกกราฟคู่เปรียบเทียบครบ 2 รูปแบบก่อนเปิดคำถามและสะท้อนคิด
- [ ] เปลี่ยนเฉพาะตัวเลขกำกับหรือบันทึกกราฟซ้ำไม่ปลดล็อกคำถาม
- [ ] ทำคำถามทั้ง 10 ข้อได้ด้วย radio/checkbox และคำแนะนำไม่เฉลยทันทีเมื่อตอบผิด
- [ ] เปลี่ยนตัวเลือกไม่นับครั้ง ส่งผิด–ผิด–ถูกนับ 3 ครั้ง ผิด 2 ครั้ง
- [ ] แตะส่งซ้ำไม่เพิ่มครั้งจนกด “ลองอีกครั้ง” และสามารถฝึกคำตอบเดิมซ้ำอย่างตั้งใจได้
- [ ] ผ่านแล้วฝึกซ้ำผิดยังคง Mastery โดยแสดงผลล่าสุดแยกกัน
- [ ] ผ่านคำถามครบแต่ยังไม่กรอกสะท้อนคิด แสดงว่ายังทำกิจกรรมไม่ครบ
- [ ] ข้อความสะท้อนคิดแสดง “ยังไม่ได้ประเมินเหตุผล” โดยไม่อ้างว่าระบบประเมินความหมายแล้ว
- [ ] หน้าสรุปแสดงจำนวนครั้ง ผลที่เคยผ่าน และข้อที่ควรทบทวนตรงกับกิจกรรม
- [ ] ย้อนดูหลักฐานตอนทำครบได้ แม้ปรับกราฟหรือข้อความปัจจุบันภายหลัง
- [ ] คืนค่ากราฟไม่ลบหลักฐานและ Mastery ส่วนเริ่มใหม่ทั้งหมดต้องยืนยันและไม่เปลี่ยน Free Exploration
- [ ] กรอกคำอธิบายภาษาไทยและปรับกราฟได้โดยข้อความไม่หาย
- [ ] เปลี่ยนแล็บหรือโหมดแล้วย้อนกลับมาได้ค่าและข้อความเดิม
- [ ] เปิดคีย์บอร์ดแล้วเลื่อนไปยังช่องกรอกและปุ่มตรวจได้
- [ ] พิมพ์ค่าทศนิยม ค่าติดลบ และล้างค่าได้ พร้อมข้อความช่วยแก้ไข
- [ ] เพิ่ม/ลบแถว แก้ข้อมูล แล้วกดนำไปใช้ได้
- [ ] โหลดหน้าใหม่แล้วข้อมูลและความคืบหน้าหายตามที่แจ้งไว้

## การเข้าถึง

- [ ] VoiceOver อ่านหัวข้อ ป้ายกำกับ ตัวเลือก และตารางได้ตามลำดับ
- [ ] VoiceOver แจ้งผลตรวจและค่าที่เลือกจากกราฟ
- [ ] VoiceOver อ่านกลุ่มคำถาม ตัวเลือกที่เลือก และคำแนะนำหลังส่งได้ โดยโฟกัสไม่หาย
- [ ] กดตัวเลือกผ่านทั้งป้ายได้ และตัวเลือกสูงอย่างน้อย 44 CSS px
- [ ] ใช้คีย์บอร์ดภายนอกเลือกโหมด ปรับกราฟ และตรวจคำตอบได้
- [ ] มองเห็นตำแหน่งโฟกัส และไม่ติดอยู่ในพื้นที่กราฟ
- [ ] แยกสถานะผ่าน/ควรปรับได้จากข้อความและสัญลักษณ์ แม้ไม่เห็นสี
- [ ] เปิด Reduce Motion แล้วไม่มีการเลื่อนแบบเคลื่อนไหวจากแอป

## บันทึกข้อจำกัด

หากพบปัญหา ให้บันทึกสถานการณ์ วิธีทำซ้ำ ผลที่เกิด และภาพประกอบ โดยไม่ใช้ข้อมูลนักเรียนจริง
