# ตรวจรับบน iPad Safari ก่อนใช้ในชั้นเรียน

สถานะ: ยังต้องตรวจบนอุปกรณ์จริง การทดสอบ WebKit จำลองช่วยตรวจถดถอย แต่ไม่ครอบคลุมคีย์บอร์ด iPad และ VoiceOver จริง

บันทึกรุ่น iPad เวอร์ชัน iPadOS/Safari วันที่ และผู้ทดสอบเมื่อดำเนินการ

## การแสดงผลและการสัมผัส

- [ ] เปิดจาก GitHub Pages และโหลดหน้าใหม่ได้โดยไม่มีไฟล์ขาด
- [ ] ใช้ได้ทั้งแนวตั้งและแนวนอน รวมถึง Split View
- [ ] หน้าเว็บไม่ล้นแนวนอน ตารางและกราฟเลื่อนภายในพื้นที่ของตัวเองได้
- [ ] ตัวอักษรไทย สระ และวรรณยุกต์แสดงครบ และอ่านได้เมื่อเพิ่มขนาดตัวอักษร
- [ ] ปุ่มและรายการเลือกกดได้สะดวกโดยไม่แตะผิด
- [ ] แตะแท่ง จุด และส่วนกราฟวงกลมแล้วอ่านค่าจากข้อความด้านล่างได้
- [ ] อ่านตารางแทนกราฟได้ โดยเฉพาะข้อมูลที่อยู่ใกล้กันหรือส่วนวงกลมขนาดเล็ก
- [ ] ขอบจอและการหมุนอุปกรณ์ไม่บังปุ่มหรือข้อความ

## กิจกรรมและคีย์บอร์ด

- [ ] ทำครบ 17 สถานการณ์ใน 4 แล็บ โดยเห็นคำแนะนำรายเกณฑ์
- [ ] คำตอบผิดไม่เพิ่มจำนวนกิจกรรมที่ผ่านเกณฑ์
- [ ] คำคาดการณ์ผิดไม่ลด Mastery และต้องกดบันทึกก่อนเริ่มทดลอง
- [ ] ต้องบันทึกกราฟคู่เปรียบเทียบครบ 2 รูปแบบก่อนเปิดคำถามและสะท้อนคิด
- [ ] เปลี่ยนเฉพาะตัวเลขกำกับหรือบันทึกกราฟซ้ำไม่ปลดล็อกคำถาม
- [ ] ทำคำถามทั้ง 34 ข้อได้ด้วย radio/checkbox และคำแนะนำไม่เฉลยทันทีเมื่อตอบผิด
- [ ] เปลี่ยนตัวเลือกไม่นับครั้ง ส่งผิด–ผิด–ถูกนับ 3 ครั้ง ผิด 2 ครั้ง
- [ ] แตะส่งซ้ำไม่เพิ่มครั้งจนกด “ลองอีกครั้ง” และสามารถฝึกคำตอบเดิมซ้ำอย่างตั้งใจได้
- [ ] ผ่านแล้วฝึกซ้ำผิดยังคง Mastery โดยแสดงผลล่าสุดแยกกัน
- [ ] ผ่านคำถามครบแต่ยังไม่กรอกสะท้อนคิด แสดงว่ายังทำกิจกรรมไม่ครบ
- [ ] ข้อความสะท้อนคิดแสดง “ยังไม่ได้ประเมินเหตุผล” โดยไม่อ้างว่าระบบประเมินความหมายแล้ว
- [ ] หน้าสรุปแสดงจำนวนครั้ง ผลที่เคยผ่าน และข้อที่ควรทบทวนตรงกับกิจกรรม
- [ ] ย้อนดูหลักฐานตอนทำครบได้ แม้ปรับกราฟหรือข้อความปัจจุบันภายหลัง
- [ ] คืนค่ากราฟไม่ลบหลักฐานและ Mastery ส่วนเริ่มใหม่ทั้งหมดต้องยืนยันและไม่เปลี่ยน Free Exploration
- [ ] กรอกคำอธิบายภาษาไทยและปรับกราฟได้โดยข้อความไม่หาย
- [ ] เปลี่ยนแล็บหรือโหมดแล้วย้อนกลับมาได้ค่าและข้อความเดิม
- [ ] เปิดคีย์บอร์ดแล้วเลื่อนไปยังช่องกรอกและปุ่มตรวจได้
- [ ] พิมพ์ค่าทศนิยม ค่าติดลบ และล้างค่าได้ พร้อมข้อความช่วยแก้ไข
- [ ] เพิ่ม/ลบแถว แก้ข้อมูล แล้วกดนำไปใช้ได้
- [ ] เมื่อไม่เปิดบันทึก โหลดใหม่แล้วข้อมูลหาย เมื่อเปิดและขึ้น “บันทึกแล้ว” โหลดใหม่แล้วประวัติ หลักฐาน Mastery และข้อความกลับมาครบ
- [ ] เครื่องร่วมกันเห็นคำเตือนเรื่องข้อมูลเดิม และปิดบันทึก/ล้างข้อมูลได้หลังยืนยัน
- [ ] ตรวจคำใบ้ทั้ง 3 ระดับและปุ่มดูเพิ่มเติม โดยจำนวนครั้งตอบไม่เพิ่มจากการดูคำใบ้
- [ ] สร้าง PDF ภาษาไทยได้ทั้งแนวตั้งและแนวนอน บันทึกลง Files และเปิดอ่านทุกหน้าได้
- [ ] แนบไฟล์ในงาน Classroom ด้วยตนเองได้ และไม่มีข้อความที่อ้างว่าแอปส่งงานให้แล้ว
- [ ] PDF มีกราฟ ข้อความสะท้อนคิดที่ยังไม่ประเมิน และคำเตือนผลแก้ไขได้ในทุกหน้า
- [ ] เปลี่ยนตัวเลือกรวมข้อความร่างแล้วต้องสร้าง PDF ใหม่ และล้างแอปไม่ลบไฟล์ที่ดาวน์โหลดแล้ว

## การเข้าถึง

- [ ] VoiceOver อ่านหัวข้อ ป้ายกำกับ ตัวเลือก และตารางได้ตามลำดับ
- [ ] VoiceOver แจ้งผลตรวจและค่าที่เลือกจากกราฟ
- [ ] VoiceOver อ่านกลุ่มคำถาม ตัวเลือกที่เลือก และคำแนะนำหลังส่งได้ โดยโฟกัสไม่หาย
- [ ] กดตัวเลือกผ่านทั้งป้ายได้ และตัวเลือกสูงอย่างน้อย 44 CSS px
- [ ] ใช้คีย์บอร์ดภายนอกเลือกโหมด ปรับกราฟ และตรวจคำตอบได้
- [ ] มองเห็นตำแหน่งโฟกัส และไม่ติดอยู่ในพื้นที่กราฟ
- [ ] แยกสถานะผ่าน/ควรปรับได้จากข้อความและสัญลักษณ์ แม้ไม่เห็นสี
- [ ] เปิด Reduce Motion แล้วไม่มีการเลื่อนแบบเคลื่อนไหวจากแอป

## บันทึกข้อจำกัด

หากพบปัญหา ให้บันทึกสถานการณ์ วิธีทำซ้ำ ผลที่เกิด และภาพประกอบ โดยไม่ใช้ข้อมูลนักเรียนจริง

## ส่วนเพิ่มเติม Phase 1.3

- [ ] แตะหรือใช้คีย์บอร์ดกับ Scatter Plot, ช่วงชั้น Histogram และกลุ่ม Box Plot แล้วอ่านสถิติได้
- [ ] ทดลองจำนวนช่วง ความกว้าง และขอบช่วงไม่เท่ากัน พร้อมตารางความถี่/ความหนาแน่น
- [ ] ทวน Q1=5.75 มัธยฐาน=7 Q3=8.25 IQR=2.5 หนวดบน=10 และค่านอกเกณฑ์=24 ของกลุ่มไม่มีพืช
- [ ] ทดลองสีทั้งสามประเภทหลายชุดสี และขาวดำ โดยยังอ่านชื่อ หน่วย และตัวเลขได้
- [ ] เห็นคำว่าเป็นภาพจำลองเมื่อเปิด 3 มิติ และอ่านข้อมูลเต็มช่วงเมื่อเลือก 3 วันสุดท้าย
- [ ] สองแกน แยกช่อง และดัชนีฐาน 100 แสดงหน่วย/วิธีแปลงชัดเจน
- [ ] แก้หน้าที่ 1 และ 2 ของข้อมูลการสังเกต แล้วนำไปใช้ได้โดยค่าจากอีกหน้าไม่หาย
- [ ] กู้คืนข้อมูลรุ่นก่อนแล้วกิจกรรมพื้นฐานและ Mastery เดิมยังอยู่ กิจกรรมใหม่เริ่มว่าง
- [ ] เปิด PDF ทั้งหมดหรือเลือกหลักฐานเฉพาะแล็บได้ ตรวจกราฟใหม่ สถิติ และคำเตือนทุกหน้า

## Workspace และการนำทางสี่ขั้น

- [ ] หน้าแรกแสดง Hero แต่เมื่อเริ่มเรียนหรือทดลองอิสระ Hero หายไป
- [ ] ส่วนหัวแสดงโหมด สถานะบันทึก และสรุป โดยไม่บังพื้นที่เรียนบนทั้งสองแนว
- [ ] คาดการณ์ → ทดลอง → อธิบาย → คำแนะนำ มีปุ่มหลักชัดเจน และขั้นที่ยังไม่เปิดบอกข้อกำหนด
- [ ] ย้อนขั้น สลับคำถาม หมุนเครื่อง กลับหน้าแรก และเลือกเรียนต่อแล้วคำตอบ/จำนวนครั้ง/Mastery ไม่เปลี่ยน
- [ ] เลือกต้นฉบับ A/B หรือหลักฐานเมื่อทำครบแล้วตัวควบคุมปรับสำเนาไม่ได้ กลับฉบับกำลังปรับได้
- [ ] กราฟ ค่าปรับหลัก และปุ่มบันทึกของกิจกรรมปกติอยู่ในพื้นที่เดียวกัน เปิดรายละเอียดเพิ่มได้โดยไม่มีแผงเลื่อนแนวตั้งซ้อน
- [ ] ปรับตัวเลขหรือ checkbox แล้วโฟกัสและเคอร์เซอร์ไม่กระโดด เมื่อเปลี่ยนชนิดกราฟยังพบตัวควบคุมที่เกี่ยวข้อง
- [ ] เปิดคีย์บอร์ดไทยและ Split View แล้วช่องกรอกกับปุ่มไม่ถูกทับ แม้ต้องเลื่อนหน้าเพิ่ม
- [ ] Free Exploration เก็บร่างเมื่อกลับกราฟ/สลับโหมด และถามก่อนเปลี่ยนชุดข้อมูลที่มีร่าง
- [ ] สรุปเปิดรายละเอียดรายแล็บ/สถานการณ์ได้ และเข้าหน้าสร้าง PDF ได้โดยไม่ต้องเปิดผลทุกข้อ
- [ ] VoiceOver อ่านขั้นปัจจุบัน ข้อกำหนดการเปิดขั้น แหล่งกราฟ และผลหลังส่งได้ครบ
- [ ] Browser Back/Forward และลิงก์ข้ามไปพื้นที่เรียนไม่ล้างผลหรือทำให้หน้าว่าง
